    Country Projection Model (CPM) Tool
    User Guide¶

    A step-by-step guide to setting up the CPM Tool, updating data, forecasting the external environment, and producing, reviewing and submitting a focus-economy forecast.

    What this guide covers¶

    • Getting Started

      System requirements and setup of Python, Visual Studio Code and the cpm_venv virtual environment.

    • Concepts

      Economy groupings and linkages, the folder structure of the tool, and the three-stage forecasting process.

    • Forecasting Workflow

      Updating the datastore, running the external economies, configuring attributes.json, the model's nine steps, and applying judgment.

    • Reports

      Generated quarterly and annual charts for both focus and external economies.

    • Hands-on Exercise

      A complete worked example for Philippines forecasting process. Updating/refresh data, external economies forecast, and Philippine forecast.

    • Reference

      Tips and common pitfalls, a command cheat sheet, a glossary, and a recap.
